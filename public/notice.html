Actualización de Biblia NG

📱 ¿Qué está pasando?

Estimados usuarios de Biblia NG, lamentamos los inconvenientes causados por los recientes cambios. Hemos actualizado la aplicación con nuevas mejoras:

  • Nuevo nombre de la aplicación (ahora es "Biblia NG")
  • Nuevo icono y branding
  • Selección múltiple de versículos
  • Funcionalidad offline mejorada
  • Mostrar nombre de usuario cuando está logueado
  • Versión y copyright en la sección "Acerca de"

⚠️ Acción Requerida

Debido a cambios técnicos en el sistema de actualización, necesita desinstalar y reinstalar la aplicación para obtener todas las nuevas funcionalidades.

Pasos para actualizar:

  • Desinstalar la aplicación actual de Biblia NG
  • Descargar la nueva versión desde el enlace de abajo
  • Instalar la nueva APK
  • Abrir la aplicación y disfrutar de las mejoras

😔 Pérdida de Datos

Lamentablemente, al desinstalar la aplicación, perderá:

  • Marcadores y resaltados
  • Progreso del juego
  • Preferencias locales

Perderá estos datos solo una vez. Después de la reinstalación, todos sus datos se guardarán correctamente y no volverá a tener este problema.

🎯 ¿Por qué este cambio?

Hemos cambiado el identificador interno de la aplicación (Package ID) para:

  • Mejorar el branding de "Biblia NG"
  • Preparar la aplicación para Google Play Store
  • Asegurar que el nombre coincida con la marca

Este cambio es necesario para el futuro de la aplicación, pero requiere una reinstalación única.

🙏 Disculpas

Lamentamos sinceramente los inconvenientes que esto causa. Entendemos que perder sus datos es frustrante, y estamos trabajando para que esto no vuelva a ocurrir.
